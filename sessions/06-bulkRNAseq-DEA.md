# 1. Introduction

Bulk RNA-seq analysis is used to compare gene expression between biological conditions, for example:

- disease vs control
- treated vs untreated
- mutant vs wild type
- different time points
- different tissues

The main goals are:

1. Import a raw count matrix
2. Prepare sample metadata
3. Perform quality control
4. Run differential expression analysis using **DESeq2**
5. Run differential expression analysis using **edgeR**
6. Compare DESeq2 and edgeR results
7. Visualize important genes using volcano plots, MA plots, PCA plots, and heatmaps
8. Perform pathway enrichment analysis using:
   - GSEA
   - Enrichr
   - clusterProfiler
   - KEGG
9. Visualize selected KEGG signaling pathways

---

# 2. Differential Expression Analysis Tools

Different tools can be used for bulk RNA-seq differential expression analysis.

| Tool | Input | Normalization | Strength |
|---|---|---|---|
| DESeq2 | Raw counts | Median-of-ratios size factors | Very robust and beginner-friendly |
| edgeR | Raw counts | TMM normalization | Flexible and powerful, especially for small sample sizes |
| limma-voom | Raw counts converted to logCPM | Voom precision weights | Fast and powerful for larger datasets |

In this tutorial, we use both:

- **DESeq2**
- **edgeR**

This allows us to compare results from two commonly used methods.

```r
# Detect gene ID column
possible_gene_cols <- c("gene", "Gene", "Geneid", "gene_id", "ensembl_gene_id")

count_data <- as.data.frame(count_data)

# Convert all count columns to numeric
count_data[] <- lapply(count_data, function(x) as.numeric(as.character(x)))

# Replace NA values with 0 if any appear after conversion
count_data[is.na(count_data)] <- 0

# Round counts to integers
count_data <- round(count_data)
```

# 14. DESeq2 Normalization Explanation

DESeq2 uses **median-of-ratios normalization**.

This corrects differences in sequencing depth between samples.

In simple terms:

```text
normalized count = raw count / size factor
```

A size factor greater than 1 means the sample had more reads than average.

A size factor less than 1 means the sample had fewer reads than average.

```r
# ============================================================
# 14. Inspect DESeq2 size factors
# ============================================================
```

# 25. Volcano Plot for DESeq2

A volcano plot displays:

- x-axis: log2 fold change
- y-axis: -log10 adjusted p-value

Genes on the right are upregulated in MS.

Genes on the left are downregulated in MS.

```r
# ============================================================
# 25. Volcano plot for DESeq2
# ============================================================

volcano_df <- res_deseq2_shrunk_df

volcano_df$status <- "Not significant"

volcano_df$status[
  !is.na(volcano_df$padj) &
    volcano_df$padj < padj_cutoff &
    volcano_df$log2FoldChange > lfc_cutoff
] <- "Upregulated"

volcano_df$status[
  !is.na(volcano_df$padj) &
    volcano_df$padj < padj_cutoff &
    volcano_df$log2FoldChange < -lfc_cutoff
] <- "Downregulated"

volcano_df$minus_log10_padj <- -log10(volcano_df$padj)

volcano_df$minus_log10_padj[!is.finite(volcano_df$minus_log10_padj)] <- NA

top_labels <- volcano_df %>%
  filter(!is.na(padj), padj < padj_cutoff, abs(log2FoldChange) > lfc_cutoff) %>%
  arrange(padj) %>%
  slice_head(n = 10)

p_volcano <- ggplot(
  volcano_df,
  aes(x = log2FoldChange, y = minus_log10_padj, color = status)
) +
  geom_point(alpha = 0.75, size = 1.5, na.rm = TRUE) +
  geom_vline(xintercept = c(-lfc_cutoff, lfc_cutoff), linetype = "dashed") +
  geom_hline(yintercept = -log10(padj_cutoff), linetype = "dashed") +
  geom_text_repel(
    data = top_labels,
    aes(label = ifelse(is.na(symbol), gene_id, symbol)),
    size = 3,
    max.overlaps = 20
  ) +
  scale_color_manual(
    values = c(
      "Downregulated" = "blue",
      "Not significant" = "grey70",
      "Upregulated" = "red"
    )
  ) +
  theme_minimal(base_size = 12) +
  labs(
    title = "DESeq2 volcano plot: MS vs Control",
    x = "log2 fold change",
    y = "-log10 adjusted p-value",
    color = "Status"
  )

p_volcano

ggsave(
  filename = file.path(assets_dir, "bulkRNAseq_DESeq2_volcano.png"),
```

# 53. Interpretation Guide

## DESeq2 and edgeR

If a gene is significant in both DESeq2 and edgeR, the result is more robust.

If a gene is significant in only one method, check:

- raw counts
- normalized counts
- expression variability
- sample outliers
- effect size
- adjusted p-value or FDR

---

## Volcano Plot

A volcano plot helps identify genes that are both:

- strongly changed
- statistically significant

Genes far to the right are upregulated.

Genes far to the left are downregulated.

Genes high on the plot are statistically more significant.

---

## Heatmaps

Heatmaps help answer questions such as:

- Do samples cluster by condition?
- Are DEGs consistently upregulated or downregulated?
- Are there outlier samples?
- Are biological replicates similar?

---

## GSEA

GSEA uses all genes ranked by expression change.

It is useful when pathway-level changes are present even if only a few genes pass DEG thresholds.

---

## Enrichr

Enrichr is useful for quick enrichment analysis using many databases.

It works well with gene symbols.

---

## clusterProfiler

clusterProfiler is useful for reproducible enrichment analysis in R.

It can perform:

- GO enrichment
- KEGG enrichment
- GSEA
- pathway visualization
- enrichment network plots

---

## KEGG Pathview

Pathview maps log2 fold changes onto KEGG pathway diagrams.

This helps visualize whether important signaling pathway genes are upregulated or downregulated.
